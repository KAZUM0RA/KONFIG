Обробка "Завантаження даних з EXCEL"

Обробка призначена для завантаження будівель, об' єктів особових рахунків і фізичних осіб з електронних таблиць Microsoft Office Excel. Для введення початкових залишків і приладів обліку і слід перейти на вкладку "Налаштування послуг" і заповнити таблицю відповідності послуг. Вказуйте в ній найменування послуг, які використані в документах EXCEL.

Формат для завантаження будівель :

  1. Тип споруди. Доступні значення: "Будівля", "Паркінг", "Гуртожиток".
  2. Область.
  3. Місто.
  4. Район.
  5. Вулиця.
  6. Корпус.
  7. Номер будинку.
  8. Поштовий індекс будівлі.
  9. Дата прийняття на баланс. Обов'язково до заповнення.
  10. Дата введення в експлуатацію. Обов'язково до заповнення.
  11. Кількість під'їздів у будівлі.
  12. Кількість ліфтів у будівлі.
  13. Загальна площа будівлі.
  14. Опалювана площа будівлі.
  15. Житлова площа будівлі.
  16. Додаткова площа будівлі.
  17. Префікс особових рахунків для будівлі.
 

Формат для об'єктів особових рахунків :

  1. Номер квартири.
  2. Поверх.
  3. Під'їзд. Вказується код під'їзду. Або номер під'їзду, якщо вимагається створити новий.
  4. Кількість кімнат.
  5. Житловий фонд. Для вказівки нежитлового фонду треба ввести "нежитловий фонд", "Ні" або "0".
  6. Загальна площа об'єкту.
  7. Опалювана площа об'єкту.
  8. Житлова площа об'єкту.
  9. Додаткова площа об'єкту.
  10. Суфікс.
 

Формат для фізичних осіб:

  1. Прізвище Ім'я По батькові фізичної особи. 
  2. Пол фізичної особи. Вказується у форматі "Дружин", "Ж" або "Жіночий".
  3. Инн.
  4. Дата народження фізичної особи.
  5. Місце народження фізичної особи.

     

    Формат для особових рахунків:

    1. Номер квартири.
    2. Суфікс квартири.
    3. Відповідальний власник особового рахунку.
    4. Кількість осіб, що мешкають на особовому рахунку. 
    5. Кількість прописаних на особовому рахунку.

     

    Формат для приладів обліку :

    1. Послуга.
    2. Заводський Номер приладу обліку.
    3. Номер квартири у якій встановлений прилад обліку.
    4. Суфікс квартири.
    5. Розрядність приладу обліку.
    6. Коефіцієнт трансформації приладу обліку.
    7. Спосіб реєстрації свідчень приладу обліку. Вказується "Витрата за період розрахунку" або "Наростаючим підсумком".
    8. Початкове свідчення приладу обліку.
    9. Тарифность приладу обліку. Заповнюється цифрами "1", "2" або "3".

    Формат для початкових залишків:

    1. Номер квартири.
    2. Суфікс квартири.
    3. Послуга.
    4. Місяць нарахування.
    5. Сума.

    При натисненні на кнопку "Зберегти послуги" - послуги призначаються на особові рахунки за допомогою документів "Управління послугами ЖКГ". При натисненні на кнопку "Зберегти початкові залишки в документ" - записується документ "Введення початкових залишків".
