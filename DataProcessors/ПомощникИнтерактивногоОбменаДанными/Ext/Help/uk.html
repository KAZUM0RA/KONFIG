Помічник інтерактивного обміну даними призначений для виконання обміну даними з можливістю попереднього перегляду завантажуваних даних. Помічник дозволяє виконувати зіставлення об'єктів двох інформаційних баз, між якими налагоджений обмін даними. Після виконання зіставлення і завантаження даних виконується вивантаження даних.

На другій сторінці помічника відображається інформація про завантаження даних і статистика зіставлення об'єктів.
По кнопці командної панелі Виконати зіставлення відкривається форма для заздалегідь перегляду завантажуваних даних і виконання зіставлення об'єктів.
По кнопці командної панелі Автоматичне зіставлення(за умовчанням) виконується процес зіставлення об'єктів для усіх рядків таблиці. Автоматичне зіставлення виконується по заданих за умовчанням полях зіставлення, при цьому дотримуються найсуворіші правила зіставлення. Рекомендується спочатку виконувати автоматичне зіставлення, а потім виконувати зіставлення вручну для об'єктів, які не були зіставлені автоматично.
По кнопці командної панелі Виконати завантаження даних виконується завантаження даних для усіх рядків таблиці. Виконувати завантаження даних рекомендується тільки після виконання зіставлення об'єктів. Якщо об'єкти не були зіставлені, то після завантаження даних будуть створені дублі незіставлених об'єктів.
Перераховані команди доступні для виклику з контекстного меню таблиці статистики зіставлення. При виклику з контекстного меню ці команди актуальні для безлічі виділених рядків таблиці.
Після того, як буде виконано зіставлення усіх об'єктів і усі дані будуть завантажені слід натиснути на кнопку Далі для вивантаження повідомлення у відповідь обміну.

На завершальній сторінці помічника буде запропоновано відкрити форму налаштування розкладу обміну даними. Форма налаштування розкладу буде відкрита у тому випадку, якщо поточний обмін даними ще не включений ні в одно з існуючих розкладів виконання обміну.
