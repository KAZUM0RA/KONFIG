У разі роботи з файловою інформаційною базою є можливість настроїти автоматичне виконання регламентних завдань.

Найменування властивості А Призначення властивості
Автоматично запускати окремий сеанс виконання регламентних завдань +

Установка прапорця настроює режим запуску окремого сеансу для виконання регламентних завдань через секунду після запуску додатка.

Якщо додаток запущений з ключем виконання регламентних завдань, тоді запуск буде пропущений, оскільки в якості сеансу, оброблювального регламентні завдання буде призначений поточний сеанс.

Окремий сеанс запускається від імені поточного користувача, а процедури виконуються в привілейованому режимі.

Повідомляти про некоректний стан виконання регламентних завдань Повідомляти користувача, що регламентні завдання не виконуються, якщо встановлений прапорець "Автоматично запускати окремий сеанс виконання регламентних завдань".
Період повідомлення, хвилин Період в хвилинах, через який буде робиться перевірка стану виконання регламентних завдань з подальшим повідомленням користувача, якщо стан некоректний.

Прим.: колонка "А" містить знак "+" там, де для зміна властивості доступно тільки Адміністраторові.

Команда Опис
Запустити окремий сеанс. Тільки для файлової ИБ. Запускає окремий сеанс для виконання регламентних завдань.
Робиться запуск окремого сеансу з параметрами, такими, що сеанс відкривається тільки для виконання регламентних завдань і вважає поточний сеанс батьківським, крім того окремий сеанс автоматично завершується при завершенні батьківського сеансу.

 

Параметри інфораціонної бази при запуску 1С Підприємства 8 для включення автоматичного виконання регламентних завдань.

Параметр

 Опис
DoScheduledJobs Виконувати регламентні завдання в сеансі, що відкривається.
SkipMessageBox Не показувати попередження, в случах, коли сеанс, що виконує завдання, вже відкритий або є інші причини, препядствующие виконанню завдань в сеансі, що відкривається.
AloneIBSession Запустити сеанс тільки для виконання регламентних завдань. Якщо сеанс для цілей виконання завдань вже відкритий, то сеанс, що відкривається, буде завершений з попередженням(чи без попередження см SkipMessageBox).

Приклади рядка програми в ярылке Windows.

Призначення

 Рядок
Включити виконання завдань в сеансі, що відкривається. "C:\Program Files\1cv82\Bin\1cv8c.exe" /CDoScheduledJobs

Запустити сеанс тільки для виконання завдань. Наприклад, якщо каталог інформаційної бази розташований на окремому комп'ютері, то цей рядок можна записати в планувальник Windows. Зайвий запуск сеансу буде автоматично завершений.

 "C:\Program Files\1cv82\Bin\1cv8c.exe" ENTERPRISE /IBConnectionString" File="" C :\Інфораціонна база"";" /NВасилий /PПароль /C" DoScheduledJobs SkipMessageBox AloneIBSession".
