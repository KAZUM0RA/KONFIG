У цілях адміністрування регламентних і фонових завдань система надає наступні можливості:

  1. Контроль виконання регламентних завдань.
  2. Регламентні завдання.
  3. Фонові завдання.

 

1. Контроль виконання регламентних завдань.

Контроль може бути або простим, або детальним.

Простий контроль - це аналіз колонок "Стан" і "Дата закінчення" на сторінці "Регламентні завдання", а також аналіз тексту поля "Повідомлення користувача і опис інформації про помилку" у формі редагування регламентного завдання.

Детальний контроль - це аналіз списку фонових завдань(на сторінці "Фонові завдання"), які були створені і виконані для виконання регламентного завдання.

Детальний контроль робиться відбором фонових завдань за регламентним завданням, що цікавить, і аналізом реквізитів фонових завдань. Слід враховувати, що зведення про виконання регламентного завдання виходять вибіркою частини відомостей про виконання останнього фонового завдання.

Прим.: відбір фонових завдань робиться тільки по команді Обновить, тому після зміни налаштування відбору треба виконати цю команду.

2. Регламентні завдання

Команда Опис
Обновить Оновлює список регламентних завдань(і список фонових з урахуванням заданого відбору, оскільки списки пов'язані).
Добавить Відкриває форму редагування нового регламентного завдання.
Змінити Відкриває форму редагування регламентного завдання.

Скопировать

 Відкриває форму редагування нового регламентного завдання, заздалегідь заповнену значеннями копійованого завдання.

Удалить

 Видаляє регламентне завдання, вибране в списку (окрім зумовлених).
Расписание Відкриває форму редагування розкладу регламентного завдання.
Виконати зараз

Виконує процедуру регламентного завдання, або в цьому сеансі(для файлової інформаційної бази), або у фоновому завданні на сервері(для серверної інформаційної бази). При виконанні процедури у фоновому завданні на сервері, не міняється дата останнього виконання, використовувана для запуску за розкладом.

Налаштування виконання регламентних завдань

Тільки для файлової ИБ. Відкриває форму налаштування виконання регламентних завдань.

Запустити окремий сеанс для виконання регламентних завдань

Тільки для файлової ИБ. Запускає окремий сеанс для виконання регламентних завдань. Фактично, робиться запуск окремого сеансу з параметрами, такими, що сеанс відкривається тільки для виконання регламентних завдань, вважає поточний сеанс батьківським і при його завершенні автоматично закривається.

 

3. Фонові завдання

Відбір Опис
По стану

Дозволяє виконати відбір по стану(додатково до відбору по періоду і за регламентним завданням) :
1) виконано
2) завершено з помилками
3) скасовано користувачем
4) виконується.

По періоду

Дозволяє виконати відбір по періоду(додатково до відбору по стану і за регламентним завданням) :
1) довільний - можна встановити нестандартний період
2) без відбору - відбір по періоду не виконується
3) ніч - стандартний період 12 годин з 21: 00-09: 00,
4) учора - стандартний період 24 години з 00: 00-23: 59 вчорашнього дня
5) сьогодні - стандартний період 24 години з 00: 00-23: 59 сьогоднішнього дня.

За регламентним завданням Дозволяє виконати відбір за регламентним завданням(додатково до відбору по стану і по періоду) :
1) прапорець означає необхідність відбору
2) найменування регламентного завдання "<не визначене>" використовується для відбору фонових завдань
запущених для виконання інших(не регламентних) задній.
Команда Опис
Обновить Оновлює список фонових завдань з урахуванням заданого відбору(і список регламентних, оскільки списки пов'язані).
Открыть Відкриває детальну форму властивостей фонового завдання.
Отменить Відміняє виконання фонового завдання(якщо виконується).
