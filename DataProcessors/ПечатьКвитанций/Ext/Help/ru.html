Обработка "Печать квитанций"

Обработка нужна для групповой печати квитанций на оплату за определенный месяц.

Необходимо заполнить следующие реквизиты:

  • Организация, для которой печатаются квитанции. Выбирается из справочника "Организации".
  • Здание, для которого печатаются квитанции. Выбирается из справочника "Здания и сооружения".
  • Месяц начислений - месяц, за который нужно напечатать квитанции, месяц должен быть закрыт.
