Файл з налаштуваннями обміну даними

Якщо файл налаштувань обміну даними загублений, то для формування нового файлу необхідно:

  • перейти в першу інформаційну базу
  • перейти у форму обмінів даними
  • вибрати необхідний обмін даними і відкрити його форму
  • у командній панелі форми слід вибрати пункт меню : "Параметри обміну даними" -> "Отримати налаштування обміну даними для другої інформаційної бази.".
