Помічник створення обміну даними призначений для створення обміну даними між двома інформаційними базами. Помічник використовується як для створення універсальних обмінів, так і для створення обмінів в розподіленій інформаційній базі.
Створення нового обміну даними виконується в два етапи. Перший і другий етапи виконуються в першій і в другій інформаційній базі відповідно. Процес створення обміну починається в одній з баз і закінчується в іншій. Для синхронізації даних між етапами створення обміну використовується тимчасовий файл з налаштуваннями.

При створенні нового обміну даними будуть визначені наступні параметри обміну :

  • Спосіб обміну даними із завданням налаштувань транспорту і перевіркою працездатності вибраного способу обміну;
  • Обмеження міграції даних між парою інформаційних баз, що обмінюються;
  • Значення за умовчанням для використання при завантаженні даних;
  • Префікс інформаційної бази, якщо він не був заданий раніше.


На завершальному кроці першого етапу налаштування обміну буде запропоновано зберегти файл з налаштуваннями для другого етапу. На початку другого етапу слід вибрати файл з налаштуваннями і продовжити створення обміну в другій інформаційній базі.

Якщо настроюється універсальний обмін, то на завершальному кроці першого етапу налаштування обміну буде запропоновано виконати вивантаження даних. Рекомендується виконати вивантаження даних для можливості подальшого зіставлення об'єктів у кінці другого етапу налаштування. Тоді після закінчення створення обміну даними буде відкритий помічник інтерактивного обміну даними.

Особливості налаштування обміну в клієнт-серверному варіанті


При налаштуванні обміну даними в клієнт-серверному варіанті інформаційної бази необхідно мати на увазі, що обмін даними виконується на комп'ютері, на якому встановлений сервер 1С :Предприятия. Для сервера 1С :Предприятия під управлінням операційної системи Microsoft Windows це шлях виду :
\\servername\resource
а для сервера під управлінням Linux :
//servername/resource.
Необхідно переконатися, що каталог обміну інформацією доступний для читання і запису користувачеві операційної системи, від імені якого запущений сервер 1С :Предприятия. Якщо це не так, то необхідно надати цьому користувачеві необхідні права, або вибрати іншого користувача для запуску сервера 1С :Предприятия з необхідними правами на каталог обміну. Ці ж рекомендації актуальні і для доступу до ресурсів FTP і електронної пошти. Детальніше про адміністрування сервера 1С :Предприятия див. документацію до платформи 1С :Предприятие.
