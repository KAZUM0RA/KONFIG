Управління підсумками включає процедури, пов'язані з підсумками регістрів накопичення і бухгалтерії, а також агрегатами оборотних регістрів накопичення. Управління підсумками розділяється на два режими:

  • Приватно використовувані можливості - дозволяють "одним натисненням" виконати найбільш часті дії, що виникають при обслуговуванні системи.
  • Повні можливості - дозволяє виконувати усі операції як з одним регістром, так і з довільним списком регістрів.

Для перемикання режимів служить гіперпосилання в правому нижньому кутку форми. Форма запам'ятовує режим відкриття.

Часто використовувані можливості

Операції з підсумками

  • Встановити період розрахованих підсумків - для прискорення роботи системи виконує установку періоду розрахованих підсумків для усіх регістрів накопичення і бухгалтерії з включеними підсумками. Для регістрів накопичення - на кінець попереднього місяця, для регістрів бухгалтерії - на кінець поточного місяця.
  • Включити використання підсумків - включає використання підсумків для усіх регістрів, у яких цей режим вимкнений(наприклад в результаті аварійного завершення якої-небудь процедури, що відключає використання підсумків).

Операції з агрегатами

  • Перебудувати і заповнити - для усіх оборотних регістрів накопичення, для яких включений режим агрегатів і встановлено їх використання, виконує операцію перестроювання використання агрегатів і виконує заповнення агрегатів. Операція може виконуватися тривалий час.
  • Отримати оптимальні агрегати - виконує отримання списку оптимальних агрегатів для усіх оборотних регістрів накопичення, для яких в Конфігураторі задані агрегати. Буде запрошений каталог, куди будуть збережені xml- файли зі списками оптимальних агрегатів. Кожен файл буде названий ідентифікатором відповідного регістра. Так, для регістра Продажі файл називатиметься Продажі.xml.

Повні можливості

У режимі повних можливостей доступний режим множинного виділення. Будь-яка дія застосовується до усіх виділених об'єктів, або до того, на якому встановлений курсор.

Підсумки

На цій закладці можна виконувати наступні операції:

  • включення і виключення використання підсумків
  • включення і виключення використання поточних підсумків
  • включення і виключення розділення підсумків
  • установка вибраного періоду розрахованих підсумків
  • виконати перерахунок підсумків, поточних підсумків або виконати перерахунок підсумків за вибраний період.

У список потрапляють тільки ті регістри, у яких для поточного користувача встановлено право Управління підсумками.

Агрегати

На цій закладці можна виконувати наступні операції:

  • установка режиму використання регістра : підсумки або агрегати
  • включення і виключення використання агрегатів
  • виконати перестроювання використання агрегатів
  • виконати оновлення агрегатів
  • виконати очищення агрегатів
  • виконати розрахунок списку оптимальних агрегатів. Буде запрошений каталог, куди будуть збережені xml- файли зі списками оптимальних агрегатів. Кожен файл буде названий ідентифікатором відповідного регістра. Так, для регістра Продажі файл називатиметься Продажі.xml. Після виконання операції, в списку регістрів жирним шрифтом будуть виділені ті регістри, для яких необхідно оновити список агрегатів на розраховані оптимальні агрегати. Оновлення необхідно виконувати в Конфігураторі.

У нижній частині форми відображається список агрегатів регістра, на якому встановлений курсор у верхньому списку.

У список потрапляють тільки ті регістри оборотні регістри накопичення, у яких для поточного користувача встановлено право Управління підсумками і в Конфігураторі задані агрегати.
