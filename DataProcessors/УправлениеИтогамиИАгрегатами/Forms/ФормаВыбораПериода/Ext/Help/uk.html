У цьому діалозі можна ввести межі періоду розрахованих підсумків для регістрів накопичення або бухгалтерії.

За умовчанням пропонуються наступні дати для установки межі розрахованих підсумків :

  • для регістрів накопичення - закінчення попереднього місяця
  • для регістрів бухгалтерії - закінчення текуещго місяця

Після зміни, дата автоматично перетвориться до дати закінчення місяця вибраної дати.

Якщо команда установки періоду расчитанных підсумків вибрана для одного регістра, то буде доступна зміна тільки одного параметра, що відповідає типу регістра.
