Довідник "Контрагенти"

Довідник призначений для зберігання списку контрагентів. Контрагент - це загальне поняття, куди включені постачальники і покупці, організації і приватні особи.

Контрагенти можуть бути згруповані по групах класифікатора довідника, наприклад, "Постачальники", "Покупці" і "СоцФонды". Довідник контрагентів має необмежену кількість рівнів вкладеності.

Редагування інформації про контрагентів робиться в окремому діалоговому вікні, що відкривається з форми списку довідника контрагентів.

При цьому вказується інформація, що характеризує контрагента:

  • Юр. / физ. обличчя. Тип контрагента. Вказується один з варіантів : юрособа або фізична особа.
  • Повне найменування контрагента. Використовується для відображення в друкарських формах документів.

На закладці "Загальні" вказуються загальні реквізити контрагента :

  • Физ. обличчя. Вказується тільки для фізичної особи. Вибирається з довідника "Фізичні особи".
  • Коди. Група реквізитів :
    • ИНН - ідентифікаційний номер контрагента, для відображення в друкарських формах документів.
    • Номер свідоцтва. Номер свідоцтва платника ПДВ.
    • Код ЄДРПОУ. Код по ЄДРПОУ.
  • Значення за умовчанням. Група реквізитів :
    • Банківський рахунок за умовчанням, для підстановки в документи. Вибирається з довідника "Банківські рахунки".
    • Договір за умовчанням, для підстановки в документи. Вибирається з довідника "Договори контрагентів".
    • Система оподаткування контрагента.

На закладці "Адреси, телефони" вказується контактна інформація контрагента : E - mail, інше, поштова адреса, телефон, факс, фактична адреса і юридична адреса.

На закладці "Додаткова інформація" вказуються будь-яка додаткова інформація про контрагента.
