Картка групи зовнішніх користувачів дозволяє переглядати і редагувати властивості групи.

Для групи користувачів можна встановити Тип учасників (наприклад, контрагенти). Група може неявно включати усіх зовнішніх користувачів для встановленого типу учасників. Для цього треба встановити прапорець Все.

При редагуванні складу користувачів групи треба враховувати, що вони неявно входять до складу груп-батьків. Для додавання великого числа користувачів можна використати команду Підібрати.
