Довідник "Файли"

Для роботи з реквізитами файлу (автор, назва, опис і так далі) використовується картка("Відкрити картку"), а для роботи з самим файлом - відповідне застосування, встановлене на комп'ютері. При редагуванні файлу його попередня версія автоматично зберігається в інформаційній базі.

Створення файлів

Для створення нового файлу

  • Відкрийте список файлів;
  • Виберіть потрібну теку;
  • Натисніть клавішу Insert чи використайте команду "Створити";
  • Виберіть спосіб створення - "з шаблону", "з файлу на диску" або "Із сканера".

Варіант створення файлу "Із сканера" стає доступним, якщо на комп'ютері підключена компонента для роботи із сканером.

Робота з файлами

Для роботи з файлами використайте команди, розташовані на командній панелі чи в підміню "Усі дії" у списку файлів або картці файлу :

Редагувати(F4)
Позначає файл як зайнятий для редагування і відкриває його зовнішнім застосуванням.
Закінчити редагування Оновлює файл в сховищі і знімає з нього позначку зайнятості для редагування
Зберегти версію Зберігає версію редагованого файлу в сховищі, але залишає його зайнятим поточним користувачем для редагування
Зайняти Позначає файл в сховищі як зайнятий поточним користувачем для редагування, але не відкриває зовнішнє застосування. Приступити безпосередньо до редагування можна буде пізніше.
Відмінити редагування Знімає з файлу позначку зайнятості для редагування
Відкрити Відкриває файл зовнішнім застосуванням для перегляду або редагування, залежно від того, чи$##$помічений;nbsp;файл як зайнятий поточним користувачем для редагування.
Зберегти як Зберігає файл файл у вказаний каталог на жорсткому або мережевому диску
Оновити з файлу на диску Оновлює файл в інформаційній базі вибраним файлом на жорсткому диску.
Підписати Відкриває діалог для вибору сертифікату і установки підпису.
Додати ЭЦП з файлу Додає вибраний файл підпису до підписів файлу
Зберегти разом з ЭЦП Зберігає файл у вказаний каталог на жорсткому або мережевому диску, а також зберігає підписи файлу - все або вибрані, залежно від налаштування "Дії при збереженні з ЭЦП"
Відкрити підпис Відкриває форму для перегляду інформації про підпис: кому виданий сертифікат, хто встановив підпис, дату установки підпису, коментар до підпису
Перевірити Перевіряє істинність виділених підписів
Перевірити все Перевіряє істинність усіх підписів
Зберегти Зберігає вибраний підпис у файл
Видалити Видаляє виділені підписи

Примітка: Якщо файл зашифрований, повнотекстовий пошук по його вмісту не працює.
