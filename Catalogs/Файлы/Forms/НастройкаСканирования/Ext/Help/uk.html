У формі виконується налаштування сканування. Форма відкривається з форми персональних налаштувань.

Встановити компоненту сканування - встановлює компоненту сканування. Якщо на Вашому комп'ютері немає сканера, встановлювати компоненту не треба. Якщо компонента вже встановлена, то замість цієї кнопки відображається версія встановленої компоненти.

Ім'я сканера - дозволяє вибрати використовуваний сканер зі списку доступних пристроїв, підключених до комп'ютера.

Використати ImageMagick для перетворення в PDF - якщо встановлена, то перетворить відскановані зображення в pdf за допомогою програми ImageMagick(на клієнтському комп'ютері, де знаходиться сканер, мають бути встановлені безкоштовні програми ImageMagick (використайте варіант: Win32 dynamic at 8 bits - per - pixel) і Ghostscript).

Шлях до програми перетворення в PDF - шлях до виконуваного файлу програми ImageMagick(за умовчанням "convert.exe"). Якщо це ім'я конфліктує з іншими програмами, треба вказати повний шлях, виду C:\Program Files\ImageMagick - 6.6.3 - Q8\convert.exe.

Формат односторінкового зображення - дозволяє вибрати один з підтримуваних форматів(BMP, JPG, GIF, PNG, TIF, PDF) для приміщення в інформаційну базу.

Формат багатосторінкового зображення - дозволяє вибрати один з підтримуваних форматів(TIF, PDF) для приміщення в інформаційну базу. Застосовується коли вибрана команда "Прийняти всі як один файл".

Тип зображення, що сканує, - дозволяє вибрати один з підтримуваних форматів(BMP, JPG, GIF, PNG, TIF) для зображень, які будуть отримані із сканера. Опція доступна, якщо формат односторінкового зображення - PDF.

Якість - якщо вибраний формат JPG, то можна настроїти його якість(100 - максимальна якість і максимальний розмір 1 - мінімальна якість і мінімальний розмір.). За умовчанням - 100.

Стискування - якщо вибраний формат TIF, можна настроїти стискування. Можливі варіанти: LZW, RLE, CCITT3, CCITT4 Без стискування. За умовчанням: Без стискування.

Дозвіл - дозволяє вибрати дозвіл сканування(DPI). Список доступних дозволів залежить від вибраного сканера.

Колірність - вибір колірності зображень, які будуть отримані із сканера(Монохромне, Градації Сірого, Кольорове).

Поворот зображення - дозволяє вибрати один з варіантів повороту зображень після сканування. Для деяких моделей сканерів ця властивість недоступна.

Розмір паперу - дозволяє вибрати розмір паперу, який поміщений в сканер. Для деяких моделей сканерів ця властивість недоступна.

Двостороннє сканування - якщо встановлено, будуть відскановані обидві сторони паперу. Для деяких моделей сканерів ця властивість недоступна.

Показувати діалог сканера - якщо Істина, перед скануванням буде показаний діалог для розширеного налаштування сканування(наприклад, вибір області сканування на аркуші паперу).

Відкрити номери відсканованих файлів - відкриває список останніх використаних номерів з яких автоматично створюються імена відсканованих файлів для кожного власника(тека файлу або документ, що Входить, Витікаючий, Внутрішній)

Примітка: при роботі під управлінням ОС Windows Server 2008, для використання сканера вам треба встановити компоненту Можливості робочого столу (Desktop Experience).
