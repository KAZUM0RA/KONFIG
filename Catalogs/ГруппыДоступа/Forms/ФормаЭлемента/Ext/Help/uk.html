Призначення груп доступу см тут.

Для групи доступу задається профіль, список учасників і обмеження доступу.

Профіль визначить права (списком ролей) і можливості обмеження прав по "розрізах"(видам доступу), наприклад, обмеження по видах Організації, Склади ...
Види доступу з профілю будуть додані в групу доступу автоматично.

Учасники задаються або довільні(користувачі і зовнішні користувачі)
або заданого виду(наприклад, користувачі, контрагенти, фізичні особи, та ін.).

Виходячи з цілей використання обмежень, що настроюються по вигляду доступу, що мається слід сформувати найменування групи доступу(детальніше в призначенні груп доступу).

Щоб настроїти обмеження треба для кожного виду доступу визначити список значень.
Для цього по видах доступу треба встановити для усіх значень "Заборонені" або "Дозволені"
а потім задати список значень або груп значень, які будуть виключеннями.

Детальніше за см довідка по групах доступу.
