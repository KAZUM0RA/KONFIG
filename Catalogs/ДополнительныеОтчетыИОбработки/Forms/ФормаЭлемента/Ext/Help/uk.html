Для додаткових обробок або звітів, призначених для роботи з конкретними об'єктами, можна визначити склад об'єктів, в яких будуть доступні команди обробки або звіту(команда Призначення обробки).

Команди обробок або звітів можуть бути доступні зі списку вибраних об'єктів, якщо встановлений прапор Використати для форм списку і з форми самого об'єкту, якщо встановлений прапор Використати для форм об'єкту.

Для обробок і звітів, які викликаються з командного інтерфейсу(не прикріпляються до об'єктів конфігурації) :

  • необхідно вказати розділи інтерфейсу, в яких команди обробок будуть доступні користувачеві через команди Додаткові звіти і Додаткові обробки.
  • для кожної команди можна вказати користувачів, для яких команда буде доступна за умовчанням(команда Швидкий доступ до команди), а також розклад, по якому запускатиметься регламентне завдання для виконання цієї команди(команда Вказати розклад команди).

За допомогою реквізиту Публікація можна включити чи відключити доступність обробки або звіту для користувача. Реквізит може набувати наступних значень:

  • використовується - обробка доступна для використання;
  • не використовується - обробка не доступна для використання;
  • режим відладки - обробка доступна для використання тільки користувачеві з роллю "Додавання і зміна додаткових обробок" або роллю "Повні права".

За допомогою команд Завантажити файл і Вивантажити файл можна оновити обробку в інформаційній базі, а також вивантажити її з бази а у файл.

Як правило, більшість обробок повинна виконуватися у безпечному режимі. Це гарантрирует, що вони не містять "ненадійний" програмний код, який виконується на сервері. Проте деякі обробки можуть вимагати виконання в небезпечному режимі. Такі обробки слід завантажувати тільки з надійних джерел(постачальників) чи перед завантаженням самостійно виконувати їх аудит.
