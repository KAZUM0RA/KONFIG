Справочник "Приборы учета"

Приборы учета – это технические устройства измеряющие объем потребленных услуг.

Справочник Приборы учета предназначен для регистрации приборов учета, закрепления приборов учета за объектами и содержит полный список приборов всех типов.

Приборы учета используются для измерения величины, характеризующей размер полученной потребителем услуги. В этом случае, стоимость услуги, начисляемая потребителю, определяется исходя из величины потребления.

Приборы учета могут определять величину потребленного ресурса, время использования, количество циклов и т.д.

Приборы учета подлежат регистрации, пломбировке и периодическим поверкам. Система позволяет регистрировать все операции с приборами учета и, периодически регистрировать их показания.

Приборы учета могут регистрировать измеряемые величины потребления услуг для разных объектов учета: зданий, подъездов, лицевых счетов.

При создании нового счетчика, необходимо указать:

  • Услуга, с которой работает прибор учета.
  • Заводской номер прибора учета.
  • Единица измерения услуги, регистрируемой прибором.
  • Коэффициент прибора учета – это то число, на которое нужно умножить показание счетчика для получения результата.
  • Тарифность прибора учета. Например, двухтарифная система предусматривает разделение суток на две тарифные зоны.
  • Способ регистрации показаний прибора учета. Используется для отражения в печатных формах документов.
  • Разрядность счётчика – это число знаков до запятой.
