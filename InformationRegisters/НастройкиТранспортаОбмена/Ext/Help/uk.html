Регістр відомостей "Налаштування транспорту обміну"

Форма дозволяє вказати налаштування різного транспорту повідомлень обміну, визначених в конфігурації, а також перевірити правильність завдання цих налаштувань.
Якщо створюється новий запис з форми списку регістра відомостей, то доступне поле "Вузол інформаційної бази".
У полі "Вузол інформаційної бази" вказується вузол плану обміну, для якого виконується налаштування параметрів транспорту.
На закладках форми задаються налаштування окремих видів транспорту.

Загальними для усіх є наступні налаштування:

  • "Вид транспорту повідомлень обміну за умовчанням" - поле для завдання виду транспорту, який використовуватиметься за умовчанням при виконанні автоматичного і інтерактивного обміну даними.
  • "Пароль архіву повідомлення обміну" - поле для завдання пароля для стискування і розпаковування архіву повідомлення обміну. Мається на увазі, що пароль стискування у базі джерелі і пароль розпаковування у базі приймачі мають бути однаковими для пари конфігурацій, що обмінюються.
  • "Ім'я файлу протоколу обміну" - поле для завдання файлу протоколу обміну. Якщо файл протоколу обміну заданий, то в процесі обміну даними, виникаючі події і помилки обміну записуватимуться в цей файл.
  • "Виконувати обмін в режимі відладки" - прапор для завдання режиму відладки обміну. Якщо цей прапор встановлений, то процес обміну даними не буде зупинений при виникненні якої-небудь помилки. Обмін завершиться до кінця з виведенням налагоджувальних повідомлень у файл протоколу обміну і журнал реєстрації. Цей режим рекомендується використати при відладці правил обміну.
