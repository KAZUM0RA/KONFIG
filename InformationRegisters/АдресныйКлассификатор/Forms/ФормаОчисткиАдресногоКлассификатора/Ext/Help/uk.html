Видалення адресних відомостей по вибраних адресних об'єктах з адресного класифікатора.

Для очищення необхідно у списку адресних об'єктів відмітити ті, адресні відомості по яких планується видалити.

Командна панель форми містить наступні кнопки:

  • Очистити - видалити адресні відомості по вибраних об'єктах; у випадку якщо регіони вибрані буде запропонований діалог, в якому необхідно підтвердити видалення адресної інформації
  • Відміна - відмінити очищення адресного класифікатора
  • - ця довідка

    • УВАГА: при очищенні віддаляються усі записи по вибраних адресних об'єктах з інформаційної бази
