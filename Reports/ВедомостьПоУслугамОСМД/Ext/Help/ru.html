Отчет "Ведомость услугам ОСМД"

Для формирования отчета нажмите кнопку "Сформировать". По умолчанию в отчет попадут все лицевые счета.

Отчет может формироваться в трех режимах – "Ведомость по действующим услугам", "Ведомость по отключенным услугам" и "История управления услугами".

В режиме Ведомость по действующим услугам в отчете отображается информация по действующим на указанную дату услугам.

Соответственно, в режиме Ведомость по отключенным услугам в отчете отображается информация по отключенным на указанную дату услугам.

В режиме История управления услугами в отчете отображается информация по услугам которые начинали или прекращали действовать в указанный период времени.
