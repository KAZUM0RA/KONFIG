Звіт "Завислі завдання"

Для формування звіту натисніть кнопку "Сформувати". У звіті виведуться "завислі" завдання які не можуть бути виконані через те, що не заповнений список ролей і виконавців.

Якщо встановлений відбір по "Координаторові виконання завдань", то в звіт виводитимуться тільки ті завдання які призначені виконавцям у об'єктах адресації, за які відповідає вказаний Координатор виконання завдань.

Щоб встановити угрупування списку завислих завдань по об'єктах адресації, виберіть варіант звіту "Завислі завдання".

Варіант звіту "Завислі завдання по ролях" дозволяє включити угрупування по ролях виконавців.

Варіант звіту "Завислі завдання по об'єктах адресації" дозволяє подивитися кількість завислих завдань в розрізі ролей виконавців.

Для перегляду одночасно як завислих, так і прострочених завдань призначений варіант звіту "Прострочені завдання".

Для детального налаштування звіту використайте команду "Усі дії - Змінити варіант".
