Отчет "Ведомость по приборам учета для общих объектов"

Для формирования отчета нажмите кнопку "Сформировать". По умолчанию в отчет попадут все показания счетчиков для зданий и подъездов.

Отчет может формироваться в двух режимах – Подробно и Кратко. В режиме Кратко в отчете не отображается информация по месяцу начисления.
