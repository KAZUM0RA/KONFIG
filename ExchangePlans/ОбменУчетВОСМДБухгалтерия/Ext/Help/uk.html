Цей план обміну призначений для демонстрації обміну даними між однотипними конфігураціями бібліотеки стандартних підсистем за правилами обміну. Використання правил обміну має на увазі гнучке налаштування обміну і можливість реалізації складних сценаріїв обміну.

План обміну визначає склад об'єктів метаданих, які беруть участь в обміні даними. Якщо у складі плану обміну у об'єкту ознака автореєстрації встановлена в значення "Заборонити", то це означає, що не усі об'єкти цього типу реєструються для вивантаження. Такі об'єкти потрапляють під дію правил реєстрації.

Використання правил реєстрації дозволяє настроювати фільтрацію даних при обміні. Налаштування обмеження міграції даних виконується на закладці "Налаштування фільтрів реєстрації" :

  • параметр "Дата початку вивантаження документів" використовується для обмеження вибірки документів заданою датою; будуть вивантажені тільки документи, дата яких більше або рівна встановленої дати, наприклад, з початку року;
  • параметри "Відбір по організаціях", "Відбір по складах" і "Відбір по підрозділах" використовуються для включення обмеження міграції даних за заданим списком організацій, складів і підрозділів відповідно. Якщо прапори скинуті, то обмеження до списків не застосовуються;
  • у таблицях "Організації", "Склади" і "Підрозділи" задаються списки елементів, які обмежують міграцію даних.


На закладці "Значення за умовчанням" вказуються значення якими заповнюються поля об'єктів при завантаженні даних, якщо поля об'єктів не заповнені.

У цьому плані обміну правила реєстрації об'єктів застосовуються для наступних типів даних :
Довідник "Організації"
Довідник "Демо : Місця зберігання"
Довідник "Демо : Підрозділи"
Документ "Демо : Вступ товарів"
Документ "Демо : Реалізація товарів"
Регістр відомостей "Демо : Відповідальні особи"
Регістр відомостей "Демо : Працівники організацій"

Для елементу довідника реєстрація змін виконується, якщо елемент належить безлічі елементів з відповідної таблиці у вузлі.

Для документу реєстрація змін виконується, якщо:

  • дата документу більше або дорівнює параметру "Дата початку вивантаження документів" у вузлі;
  • і організація і склад і підрозділ* належать безлічі елементів з відповідних таблиць у вузлі(за умови установки прапорів використання обмежень по таблицях).

* Примітка: відбір по підрозділах використовується тільки для документу "Демо : Реалізація товарів".
