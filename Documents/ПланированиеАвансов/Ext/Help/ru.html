Документ "Планирование авансов"

Документ предназначен для планирования авансовых платежей за ресурсные услуги.

Необходимо заполнить следующие реквизиты:

  • Организация. В данном реквизите указывается собственная организация, от имени которой оформляется документ.
  • Здание. В этом поле необходимо указать здание, для лицевых счетов которого будет произведено начисление.
  • Услуга. В этом поле необходимо указать услугу, за которую будет произведено начисление.
  • За период. В этом поле указываем период, в котором будет учтено текущее начисление.
  • Сумма документа. в этом поле указывается денежная сумма за выбранную услугу, которую необходимо распределить между лицевыми счетами.
  • Параметры базы распределения. В этой группе задается пропорция распределения суммы документа между потребителями.
    • за период. Расчетный период, в котором будет выбрана услуга базы распределения.
    • Услуга базы распределения. Услуга, начисление по которой будет учитываться как коэфициент для вычисления доли от суммы документа.  
     Примечание: Параметры базы распределения не обязательны к заполнению. Заполнение табличной части без заполненых параметров базы распределения, обязывает пользователя указывать для кажного лицевого счета количество базы распределения (коэфициент) вручную.  Так же табличная часть может быть заполнена полностью в ручную.
  • Лицевые счета. Табличная часть:
    • Лицевой счет. В данное поле вводится элемент справочника "Лицевые счета".
    • Объект лицевого счета. Заполняется автоматически при указании лицевого счета.
    • Количество базы распределения. Указывается коэфициент для рассчета доли в начислении. Заполняется автоматически при установленных параметрах распределения или вручную.
    • Сумма аванса. Заполняется автоматически сумма апванса по услуге у данного лицевого счета. 
    • Сумма планируемого аванса. Рассчитывается автоматически при нажатии на кнопкум "Распределить" .
