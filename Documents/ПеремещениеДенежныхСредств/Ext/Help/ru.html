Документ "Перемещение денег"

Документ "Перемещение денег" предназначен для осуществления перемещения денежных средств.

В документе необходимо заполнить следующие реквизиты:

  • Организация, для которой оформляется документ. Выбирается из справочника "Организации".
  • Сумма. Указывается сумма перемещения в валюте денежных средств.
  • Источник денежных средств. Группа реквизитов:
    • Способ оплаты источника. Указывается один из вариантов: безналичные или наличные.
    • Банковский счет источника организации, для которого осуществляется перемещение. Становится доступным для указания при выбранном способе оплаты - безналичные. Выбирается из справочника "Банковские счета".
    • Касса источника организации, для которой осуществляется перемещение. Становится доступным для указания при выбранном способе оплаты - наличные. Выбирается из справочника "Кассы".
  • Получатель денежных средств. Группа реквизитов:
    • Способ оплаты получателя. Указывается один из вариантов: безналичные или наличные.
    • Банковский счет получателя организации, на который осуществляется перемещение. Становится доступным для указания при выбранном способе оплаты - безналичные. Выбирается из справочника "Банковские счета".
    • Касса получателя организации, в которую осуществляется перемещение. Становится доступным для указания при выбранном способе оплаты - наличные. Выбирается из справочника "Кассы".
  • Комментарий. Указывается комментарий к документу.
