Документ "Переміщення грошей"

Документ "Переміщення грошей" призначений для здійснення переміщення грошових коштів.

У документі необхідно заповнити такі реквізити:

  • Організація, для якої оформляється документ. Вибирається з довідника "Організації".
  • Сума. Вказується сума переміщення у валюті грошових коштів.
  • Джерело грошових коштів. Група реквізитів:
    • Спосіб оплати джерела. Вказується один з варіантів: безготівкові або готівкові.
    • Банківський рахунок джерела організації, для якого здійснюється переміщення. Стає доступним для вказівки при обраному способі оплати - безготівкові. Вибирається з довідника "Банківські рахунки".
    • Каса джерела організації, для якої здійснюється переміщення. Стає доступним для вказівки при обраному способі оплати - готівка. Вибирається з довідника "Каси".
  • Одержувач коштів. Група реквізитів:
    • Спосіб оплати одержувача . Вказується один з варіантів: безготівкові або готівкові.
    • Банківський рахунок одержувача організації, на який здійснюється переміщення. Стає доступним для вказівки при обраному способі оплати - безготівкові. Вибирається з довідника "Банківські рахунки".
    • Каса одержувача організації, в яку здійснюється переміщення. Стає доступним для вказівки при обраному способі оплати - готівка. Вибирається з довідника "Каси".
  • Коментар. Вказується коментар до документа.
