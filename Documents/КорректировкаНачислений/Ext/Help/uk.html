Документ "Коригування нарахувань"

Документ призначений для оформлення коригування нарахувань по особових рахунках в закритих розрахункових періодах.

Необхідно заповнити наступні реквізити:

  • Організація. У цьому реквізиті вказується власна організація, від імені якої оформляється документ. Вибирається з довідника "Організації".
  • Будівля. У цьому реквізиті вказується інформація про будівлю, для якої якого коригуються свідчення. Вибирається з довідника "Будівлі і споруди".

Таблична частина може бути заповнена за допомогою підбору або вручну. при підборі заповнюються тільки поле особовий рахунок і поле об'єкт особового рахунку.

Таблична частина :

  • Послуга. Вказується усуга, по якій необхідно скоректувати нарахування. Заповнюється тільки вручну. Вибирається з довідника Послуги.
  • Особовий рахунок. Вказується особовий рахунок, нарахування по якому потребують коригування. Заповнюється підбором або вручну вибирається з довідника "Особові рахунки".
  • Об'єкт особового рахунку. Заповнюється автоматично при виборі особового рахунку.
  • Період коригування. Вказується нарахування по якому періоду проводиться коригування.
  • Вид нарахування. Вказується вид коригованого нарахування.
  • Сума коригування. Вказується сума на яку треба скоректувати нарахування. Знак мінус(-) змінює напрям коригування на протилежне.
  • Льгота. Указывается льгота. Поле активно если выбран вид начисления "Льгота". Выбирается из справочника "Льготы".
  • Пільговик. Вказується пільговик. Вибирається з довідника "Фізичні особи".
