Документ "Корректировка начислений"

Документ предназначен для оформления корректировки начислений по лицевым счетам в закрытых расчетных периодах.

Необходимо заполнить следующие реквизиты:

  • Организация. В данном реквизите указывается собственная организация, от имени которой оформляется документ. Выбирается из справочника "Организации".
  • Здание. В данном реквизите указывается информация о здании, для которого которого корректируются показания. Выбирается из справочника "Здания и сооружения".

Табличная часть может быть заполнена с помощью подбора или вручную. при подборе заполняются только поле лицевой счет и  поле объект лицевого счета.

Табличная часть :

  • Услуга. Указывается усуга, по которой необходимо скорректировать начисление. Заполняется только вручную. Выбирается из справочника Услуги.
  • Лицевой счет. Указывается лицевой счет, начисления по которому нуждаются в корректировке. Заполняется подбором либо вручную  выбирается из справочника "Лицевые счета".
  • Объект лицевого счета. Заполняется автоматически при выборе лицевого счета.
  • Период корректировки. Указывается начисления по какому периоду проводится корректировка.
  • Вид начисления. Указывается вид корректируемого начисления.
  • Сумма корректировки. Указывается сумма на которую нужно скорректировать начисление. Знак минус (-) изменяет направление корректировки на противоположное.
  • Льгота. Указывается льгота. Поле активно если выбран вид начисления "Льгота". Выбирается из справочника "Льготы".
  • Льготчик. Указывается льготчик. Выбирается из справочника "Физические лица".
