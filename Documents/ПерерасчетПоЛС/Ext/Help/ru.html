Документ "Перерасчет по лицевому счету"

Документ предназначен для перерасчета по лицевым счетам.

В шапке документа указывается период перерасчета, здание, услуга, по которой будет перерасчет (если услуга не указана - перерасчет по всем услугам).

В табличной части "Лицевые счета" указываются лицевые счета, для которых будет произведен перерасчет.
