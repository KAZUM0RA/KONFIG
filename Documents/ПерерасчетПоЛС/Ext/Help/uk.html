Документ "Перерахунок по особовому рахунку"

Документ призначений для перерахунку по особових рахунках.

У шапці документа вказується період перерахунку, будівля, послуга, за якою буде перерахунок (якщо послуга не вказана - перерахунок по всіх послугах).

У табличній частині "Особові рахунки" зазначаються особові рахунки , для яких буде проведено перерахунок.
