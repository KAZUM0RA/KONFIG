Документ "Поступление на счет"

Документ "Поступление на счет" предназначен для учета поступлений безналичных денежных средств.

В зависимости от установленного вида операции с помощью данного документа может быть зафиксировано поступление безналичных денежных средств по различным операциям:

  • Поступление от лицевого счета;
  • Расчеты по субсидиям;
  • Расчеты по льготам.

Операция "Поступление от лицевого счета" предназначена для оформления поступления безналичных денежных средств от лицевого счета.

Если необходимо оформить операцию получения денег от контрагента за льготы, то устанавливается вид операции "Расчеты по льготам".

В случае оформления операции получения денег от контрагента за субсидии, устанавливается вид операции "Расчеты по субсидиям".

 

Для любого вида операции необходимо заполнить следующие реквизиты:

  • Организация, для которой оформляется поступление на счет. Выбирается из справочника "Организации".
  • Вид операции. Указывается вид операции документа. Предлагается выбор из списка: от покупателя, от поставщика, от подотчетника или в доходы.
  • Банковский счет организации, для которой оформляется поступление. Выбирается из справочника "Банковские счета".
  • Сумма. Указывается сумма платежа в валюте расчетного счета.
  • Номер вх. док. Номер входящего документа.
  • Дата вх. док. Дата входящего документа.
  • Комментарий. Указывается комментарий к документу.

Для вида операции "Расчеты по льготам" или "Расчеты по субсидиям" становятся видимыми следующие реквизиты:

  • Контрагент. Выбирается из справочника "Контрагенты".
  • Договор контрагента, выбирается из справочника "Договоры контрагентов".
  • Услуга, выбирается из справочника "Услуги".

Для вида операции "Поступление от лицевого счета" становятся видимыми следующие реквизиты:

  • Лицевой счет. Выбирается из справочника "Лицевые счета".
  • Табличная часть "Услуги". Указывается услуга, месяц начисления и сумма полученных средств.
