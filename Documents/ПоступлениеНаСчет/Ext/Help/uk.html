Документ "Надходження на рахунок"

Документ "Надходження на рахунок" призначений для обліку надходжень безготівкових грошових коштів.

Залежно від встановленого виду операції за допомогою даного документа може бути зафіксовано надходження безготівкових грошових коштів з різних операцій:

  • Надходження від особового рахунку;
  • Розрахунки за субсидіями;
  • Розрахунки за пільгами.

Операція "Надходження від особового рахунку" призначена для оформлення надходження безготівкових грошових коштів від особового рахунку.

Якщо необхідно оформити операцію отримання грошей від контрагента за пільги, то встановлюється вид операції "Розрахунки за пільгами".

У разі оформлення операції отримання грошей від контрагента за субсидії, встановлюється вид операції "Розрахунки по субсидіях".

 

Для будь-якого виду операції необхідно заповнити такі реквізити:

  • Організація, для якої оформляється надходження на рахунок. Вибирається з довідника "Організації".
  • вид операції. Зазначається вид операції документа. Пропонується вибір зі списку: від покупця, від постачальника, від подотчетнік або в доходи.
  • Банківський рахунок організації, для якої оформляється надходження. Вибирається з довідника "Банківські рахунки".
  • Сума. Вказується сума платежу у валюті розрахункового рахунку.
  • Номер вх. док. Номер вхідного документа.
  • Дата вх. док. Дата вхідного документа.
  • Коментар. Вказується коментар до документа.

Для виду операції "Розрахунки за пільгами" або "Розрахунки по субсидіях" стають видимими такі реквізити:

  • Контрагент. Вибирається з довідника "Контрагенти".
  • Договір контрагента, вибирається з довідника "Договори контрагентів".
  • Послуга, вибирається з довідника"Послуга".

Для виду операції "Надходження від особового рахунку" стають видимими такі реквізити:

  • Особовий рахунок. Вибирається з довідника "Особові рахунки".
  • Таблична частина "Послуги". Вказується послуга, місяць нарахування і сума отриманих коштів.
