Документ "Расход с банковского счета"

Документ  предназначен для учета расходов безналичных денежных средств.

 

Необходимо заполнить следующие реквизиты:

  • Организация, для которой оформляется расход со счета. Выбирается из справочника "Организации".
  • Банковский счет организации, для которой оформляется расход. Выбирается из справочника "Банковские счета".
  • Сумма. Указывается сумма платежа в валюте расчетного счета.
  • Номер вх. док. Номер входящего документа.
  • Дата вх. док. Дата входящего документа.
  • Комментарий. Указывается комментарий к документу.
  • Контрагент. Выбирается из справочника "Контрагенты".
  • Договор контрагента, выбирается из справочника "Договоры контрагентов".
  • Вид взаиморасчетов, выбирается вид взаиморасчетов с контрагентом (за запасы, основные услуги или прочие услуги).
