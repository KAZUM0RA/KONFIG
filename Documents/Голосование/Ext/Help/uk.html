Документ "Голосування"

Документ призначений для реєстрації в системі інформації заповнених бланків для голосування.

Документ може бути створений в режимі введення на підставі документа "Інформаційний лист для голосування".

Документ "Голосування", створений в режимі введення на підставі документа "Інформаційний лист для голосування", заповнюється автоматично.
