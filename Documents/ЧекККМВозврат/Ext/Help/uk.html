Документ "Чек ККМ повернення"

Документ "Чек ККМ повернення" призначене для обліку повернень готівкових грошових коштів через касові апарати.

Необхідно заповнити наступні реквізити:

  • Організація для якої оформляється вступ в касу. Вибирається з довідника "Організації".
  • Вид операції. Вказується вид операції документу.
  • Особовий рахунок. Особовий рахунок від якого поступили засоби.
  • Каса організації, для якої оформляється вступ.
  • Сума. Вказується сума платежу у валюті каси.
  • Коментар. Вказується коментар до документу.
