Документ "Начисление по лицевому счету"

Начисление по лицевому счету происходят, начиная с даты, его открытия, и прекращаются с даты, его закрытия. В промежутке между этими может быть изменен список потребляемых услуг, количество проживающих и прописанных. Неизменными остаются ответственный владелец и объект. При их изменении лицевой счет закрывается и создается новый.

Документ начисления для одного лицевого счета может быт создан один раз в месяц.
