Форма "Установка поргов по услугам"

Форма "Установка порогов по услугам" служит для назначения пороговых (блочных) тарифов.

Необходимо заполнить:

значение порога - мксимальное количество ресурса, начисляемое по тарифу текщего порога (блока);

Ед.Изм - единица измерения ресурса; 

Тариф - тариф порога (блока).
