У формі виконуються персональні налаштування електронного цифрового підпису(ЭЦП). Форма відкривається з форми персональних налаштувань.

Налаштування Опис
Дії при збереженні з ЭЦП

Задає поведінку при виконанні команди "Зберегти з ЭЦП":

  • Зберігати усі підписи - усі підписи зберігаються;
  • Запитувати - вибір підписів, що зберігаються, здійснюється в формі.
Розширення для зашифрованих файлів Задає розширення для зашифрованих файлів при відправці поштою, при виконанні команди "Зберегти як" і при експорті теки.
За умовчанням "p7m".
Шлях модуля криптографії(для веб клієнта під управлінням Linux) Задає шлях модуля криптографії для операцій з файлами(розшифровка, підписання, перевірка підпису, перегляд сертифікату).
Особистий сертифікат для шифрування

Персональний сертифікат електронного цифрового підпису(ЭЦП) для шифрування даних. При виборі сертифікатів для шифрування цей сертифікат буде завжди відмічений. Це треба для того, щоб не можна було зашифрувати дані без можливості їх розшифровки.
