Звіт Структура підлеглості призначений для виведення батьківських і підпорядкованих документів. Документ, для котого сформований звіт відображається жирним шрифтом. Дерево батьківських документів будується вгору-управо від документу, для якого формується звіт. Дерево дочірніх документів будується вниз-управо від документу, для якого формується звіт.

За допомогою подвійного клика на будь-якому виведеному в звіт документі можна відкрити цей документ для перегляду.

Воспользовашись кнопкою Вивести для поточного можна сформувати звіт Структура підлеглості для документу, на якому ми на даний момент спозиционировались.

Для того, щоб оновити звіт використайте кнопку Оновити.
